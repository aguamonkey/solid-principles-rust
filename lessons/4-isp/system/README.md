## Let the consumer name its need

The report path accepts BuildReader, which exposes page and lookup. It does not require record or acknowledge. The HTTP composition root can hold the complete Journal without passing that whole capability set into every policy.

Read [src/console/ports.rs](../../../src/console/ports.rs), then [the shared contracts](../../../tests/console_contracts.rs) and [HTTP tests](../../../tests/console_http.rs).

Run the console and use the corresponding study lens. Explain the promise before changing the code. Compiler acceptance alone is not proof of the domain behaviour.
