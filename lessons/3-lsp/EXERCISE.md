# Exercise · Artifact manifest

[Lesson](README.md) · [Solution notes](SOLUTION.md)

Implement a PrefixManifest wrapping another Manifest. Prefix successful artifact names and preserve Unavailable. Run the same contract cases, including empty success and unavailable outcomes.

Before editing, name the owner, one behaviour that must remain stable, and one alternative. Implement the change in your editor and add a behavioural test. Run the repository checks before reviewing solution notes. The exercise is not preimplemented.
